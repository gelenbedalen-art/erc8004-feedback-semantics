ERC-8004 feedback semantics

Enter an agent ID on Arc mainnet. The page reads its feedback directly from the canonical Reputation Registry with eth_call, classifies each entry by its tag, and compares the result with the ArcID indexer. Read-only: no wallet, no signing, no transactions.

How to read this

  • Registry summary is the registry's own getSummary(agentId, clients, "", ""): a plain mean of every non-revoked entry, whatever its tag.
  • ArcID values come from the public API at api.arcusid.com. That API does not allow calls from other websites, so when the browser cannot reach it the page uses the census snapshot committed in the repo (fetched from the same API on 2026-10-21) and says so. On-chain values are always read live.
  • Our reading takes the mean of each client's entries, then the mean across clients (the same grouping ArcID uses). Binary flags and amounts in other units are left out; 0-100 ratings and percentages count.
  • Tag meanings come from the 8004scan Feedback Data Profile. Rules marked inferred (metadataVerified, stbAgentActive, score) are our reading of the tag name and are not documented by their writers.
  • ArcID's Trust Score formula is not public. This page does not compute a corrected Trust Score.
